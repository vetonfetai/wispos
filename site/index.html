Install

Try it first, install when you're ready

About 15 minutes from download to desktop.

  1. Download

    Get wisp-os-0.1-x86_64.iso (902 MB).

  2. Make a USB stick

    Open balenaEtcher (free), pick the file and a USB stick of 2 GB or more, click Flash.

  3. Start from USB

    Switch the PC on and press the boot menu key: F12 on ThinkPad and Dell, F9 on HP, Esc on ASUS. Choose the stick.

  4. Try, then install

    Everything runs from the stick. When you're happy, double-click Install Wisp OS, pick the disk and set a password.

Installing erases the disk you choose, including Windows and your files. Back up first. Trying Wisp from the USB stick changes nothing.

FAQ

Questions

Is it really free?

Yes. No price, no account, no ads. It's built on Alpine Linux and the code is on GitHub.

Will it delete Windows?

Only if you install it. Trying it from USB changes nothing. Installing replaces everything on the chosen disk; installing next to Windows isn't supported yet.

Can I use Microsoft Office or Photoshop?

Windows programs don't run on Wisp. LibreOffice (in the App Store) opens Word, Excel and PowerPoint files, GIMP edits photos, and Office 365 and Google Docs work in Firefox.

How do updates work?

Wisp checks once a day and shows a notification. Open Settings → Updates and click Install updates. Wisp and all your apps update together, and your files and settings stay.

My laptop shows more than 178 MB. Why?

178 MB is on a 1 GB PC. With more memory, Linux keeps bigger buffers for itself, and graphics and Wi-Fi drivers on real hardware use some too, so an 8 GB laptop usually shows 250–350 MB. Linux scales this down automatically on smaller PCs, so it never stops a 1 GB PC from working.

My Wi-Fi doesn't appear.

Most Intel, Realtek, Atheros and MediaTek Wi-Fi works. Some Broadcom chips (common in older HP and Dell laptops) aren't supported yet; use a cable or a USB Wi-Fi adapter meanwhile.

Does it run on a Mac?

Not on Apple-chip Macs (M1 and newer). To try Wisp on any computer, run it in a virtual machine.
